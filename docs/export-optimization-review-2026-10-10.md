# Claude Export 导出优化记录

日期：2026-10-10。参考同级 `ChatVault Exporter`（package 版本 1.7.0），按差异迁移现有导出功能的优化。保留当前项目已有的下载生命周期、完整性检查、取消信号与结构化错误修复。

## 已完成

| 范围 | 优化结果 | 主要位置 |
| --- | --- | --- |
| 长对话 PDF / 图片 | 测量、列表、表格及绘制循环分片执行，允许浏览器处理取消操作；复用内容统计，减少重复扫描 | `utils.js`、`engine.js`、`builders/pdf.js`、`builders/image.js` |
| PDF 内存 | 根据设备内存和已解码图片占用控制页面编码并发；保持原有纸张尺寸与渲染质量档位 | `builders/pdf.js` |
| 图片内存与取消 | 成功、失败、取消和像素预算拒绝时释放图片、Bitmap、临时 Canvas；等待其他工作线程结束再清理 | `media.js`、`utils.js`、`platform-fetchers.js` |

| 表格及完整性 | Markdown 转义管道符留在单元格内；图片、列表、表格计入有效消息，纯空白与空对象计入空消息 | `platform-fetchers.js` |

| 批量导出 | 消费结果后释放预取槽位；结束时取消并等待剩余预取，防止清理后又产生附件资源 | `content.js` |
| 导出操作 | 同步占用任务锁，防止连续点击覆盖控制器；异常预检也释放锁；校验抓取前后的会话，并固定导出标题、来源网址 | `content.js` |
| Claude 组织 | 优先选择 API 明确标记的活跃组织；缺少会话 ID 时直接停止，避免多余组织请求 | `platform-fetchers.js` |
| 文件名 | 避免 Windows 保留设备名、尾随点和截断的 emoji | `utils.js` |
| 检查脚本 | 纳入 popup 语法检查，任一模块检查失败即停止 | `package.json` |

## 平台与功能范围

- 现有导出格式、界面入口、会员规则与集成功能保持原范围。
- 内容脚本仅在 `claude.ai` 启动；读取边界拒绝其他平台记录。
- 产品平台检测与 API 抓取遵循现有 `supportedPlatforms: ["claude"]` 配置，并检查当前站点。
- 注册表和安装包仅包含 Claude extractor；权限与 host permissions 未变。
- 保留共享模块的纯数据转换辅助函数和已有离线测试；它们不扩展产品的页面读取范围。
- 本次按文件差异迁移，未执行全量 `npm run sync`。

## 验证

`npm run release:check` 通过：语法检查、165 条测试（162 通过，3 条原有非 Claude DOM 测试跳过），以及扩展打包。

新增/迁移的测试覆盖跨分块中文与 emoji、流读取错误、图片内存释放、PDF / 图片取消、完整分页、Word 实际 PNG 转换、1,200 个 DOM 候选、转义表格、活跃组织、防重复点击、会话切换及平台请求隔离。

安装包为 `dist/claude-export-1.3.0.zip`；版本维持 1.3.0。已核对安装包包含本次源码、仅注入 Claude、没有其他平台 extractor，且发布 manifest 移除了开发用 key。

验证使用本地自动化和模拟 Canvas / API；尚未在真实登录的 Claude 页面与桌面 Word 中做人工验收。

## 后续可优化的现有流程

1. **Notion / Obsidian 全会话同步的 DOM 前置条件。** 这两条路径仍会在页面解析为空时提前报错，而本地全会话导出已经允许使用 API。可统一获取流程，在 DOM 虚拟化时减少误判，同时保留所选消息模式的快照规则。
2. **多组织账号没有活跃标记时的组织定位。** 本次修正明确活跃标记的优先级；API 没有活跃标记时仍回退到首个有效组织。应基于真实 Claude 多组织响应确定当前组织来源，再做有界恢复。
3. **后续核心同步的范围控制。** 现有 `scripts/sync-core.mjs` 会全量覆盖核心及部分关联模块，可能带入上游功能或覆盖产品本地修复。后续可以改为优化白名单和差异合并，配合本次平台隔离测试验收。
